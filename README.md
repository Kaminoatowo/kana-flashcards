# Kana Trainer

A single-page flashcard app for learning Japanese hiragana and katakana, built with vanilla HTML/CSS/JS.

## Features

- **Three modes** — Hiragana only, Katakana only, or mixed
- **Group selection** — choose which kana groups to study
- **Spaced repetition** — cards are scheduled using the SM-2 algorithm
- **Score tracking** — correct, incorrect, and remaining counts per session
- **Streak counter** — tracks consecutive days of practice
- **Kana reference tables** — full hiragana and katakana charts on the stats page
- **Offline-capable** — no server needed, progress saved in `localStorage`

## Usage

Open `index.html` in any modern browser — no build step required.
